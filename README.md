# 🌸 Bloomify – Online Flower Bouquet Ordering & Delivery System

A Django-based web application that allows customers to browse flower bouquets, manage their shopping cart, place orders, and track deliveries through an easy-to-use online platform.

## 📌 Project Overview

**Bloomify** is an online flower bouquet ordering and delivery management system developed using Django.

The application provides customers with a convenient way to explore different flower bouquets, view product details, add products to their cart, complete checkout, and manage their orders.

An administration system is also provided for managing products, categories, customers, and orders.

## ✨ Features

### 👤 Customer Features

- User registration and login
- Browse flower bouquet categories
- View bouquet details
- Add bouquets to cart
- Update cart quantity
- Remove items from cart
- Checkout and place orders
- Manage delivery details
- View order history
- Track order status

### 🛠️ Admin Features

- Manage customers
- Manage flower categories
- Add, update, and delete bouquets
- Manage product information
- Manage product images
- View customer orders
- Update order status
- Manage application data through Django Admin

## 🏗️ Project Modules

- User Authentication
- Category Management
- Product/Bouquet Management
- Shopping Cart
- Checkout
- Order Management
- Delivery Management
- Admin Panel
